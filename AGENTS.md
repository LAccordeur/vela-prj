## Development

Please consider the following when coding.

* Install the necessary python library when necessary and record it in the requirements.txt
* Before making any code changes, provide a clear modification plan and wait for my approval before proceeding.
* When adding a new core function, add corresponding tests under `tests/`.
* Document all implementation changes in `doc/CHANGE.log`, and record the key design decisions in `doc/DESIGN.md`.
* Read `doc/CHANGE.log` and `doc/DESIGN.md` to understand the latest status and overall design of the project before making any changes.



## Review Guidelines

Please consider the following when reviewing code contributions.

### Documentation

* New features must include updates to the documentation comments. Link to relevant structs and methods to increase the value of documentation.
